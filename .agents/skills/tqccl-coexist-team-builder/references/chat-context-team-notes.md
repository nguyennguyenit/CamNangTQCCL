## Important Tactic Name Corrections

- `Không Đánh Mà Thắng` = `非攻制胜` = Hán-Việt `Phi Công Chế Thắng`; not `不战而胜`.
- `Dốc Sức Tính Kế` = `竭力佐谋`. It must be paired with another non-self active tactic on the same holder; do not pair it with passive/formation/troop tactics.
- `Thời Cơ Chiến Thắng` = `临机制胜`. It is an instant active damage/status tactic with 1-turn cooldown, not a healing tactic.
- `Phi Hùng Quân` rewards active healing and accumulates healing value for damage; prefer active healing tactics on the support slot when using Phi Hùng.
- `Hổ Báo Kỵ` is for assault/basic-attack teams, not the active-magic Phi Hùng/Ngụy pháp direction.

## Mechanic Notes From Chat

- CO/Vô Song Chân Cơ benefits from active tactics; avoid putting `Dốc Sức + Tạm Lánh` on her because `Tạm Lánh` does not consume the `Dốc Sức` active-rate boost.
- CO Chân Cơ with `Dốc Sức + Cắt Xương` is ideal if `Cắt Xương` is free. If not free, `Dốc Sức + Anh Thành Tự Thủ` is a practical Phi Hùng-friendly fallback.
- `Anh Thành Tự Thủ` can heal again if repeated, but its `Nghỉ Ngơi/休整` state does not stack as two independent layers on the same target.
- Repeating a preparation tactic does not make it instant; avoid 1-turn preparation tactics on CO Chân Cơ when the goal is reliable repeated active value.
- `Binh Vô Thường Thế` is not optimal on SP Quách Gia in the discussed Phi Hùng/Phong Thi setup because he is not a repeated basic-attack core.
- If using `Phi Hùng Quân + Phong Thi Trận`, the main-damage general should be the chủ tướng because Phi Hùng damage follows the chủ tướng and Phong Thi buffs chủ tướng damage.
