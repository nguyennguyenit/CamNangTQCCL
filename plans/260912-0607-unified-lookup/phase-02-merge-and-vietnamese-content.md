## Architecture và exact public contract

Một merged in-memory model sinh ba payload files + manifest từ **một captured
verified raw input set**. Builder đọc mỗi source/baseline/registry/translation
byte sequence vào private buffers một lần, kiểm schema/hash trên chính buffers
đó, rồi parse/hash/build chỉ từ buffers; không validate pathname A rồi reopen B.
Bảo toàn thứ tự legacy records, append new IDs theo lexical ID để output
deterministic. JSON UTF-8, indent 2, newline cuối, sorted object keys; không
wall-clock trong generated bytes.

**Hai arrays giữ nguyên basename** `heroes-dict.json`, `tactics.json`. Giữ mọi
existing keys/types cần consumer, nhất là `viet,hanViet,chinese,aliases`, string
stats/cost; bổ sung `id` validated against actual helpers và `lookup` bên dưới.
`effect` giữ selected Chinese mechanics cho legacy contract; `effectViet` phải
dịch đúng selected effect. Provider provenance không được đưa vào arrays.

```text
CommonLookup = {
 conditions:[{kind:"season"|"scenario"|"requirement",textVi:string}],
 missingFields:string[],
 revisions:[{labelVi:string,effectiveDate:string|null,textVi:string,isCurrent:boolean}]
}
Hero.lookup = CommonLookup + {
 variant:"base"|"sp"|"co"|"40y",
 selfTacticId:string|null,inheritTacticId:string|null,advisorId:string|null,
 growth:{luc,tri,thong,toc,chinh,mi}:number|null per key,
 otherAptitudes:{infantry:string|null,navy:string|null},
 categoryVi:string|null,exclusiveTitleVi:string|null,
 civil:{roleVi,bonusVi,specialtyVi,tacticBonusVi}:string|null per key,
 civilInnatePoints:number|null,collectibleBonusVi:string|null,redRulesVi:string|null,
 flags:{isCollectible,isDynamicOpen,isMusou,isCO,isSp}:boolean|null per key
}
Tactic.lookup = CommonLookup + {
 activationRate:number|null,cooldown:number|null,maxUsers:number|null,pointCost:number|null,
 effectTypeVi:string|null,exchangeConditionVi:string|null,
 acquiredFromVi:string[],inheritedFromIds:string[],conflictsVi:string|null
}
```

Existing `pending` derived anew from final usable effect: real source/local effect
clears old true; both absent set true. `targetViet` same freshness contract as effect.
Known enum transforms are explicit tables; unknown nonempty enum fails validation
until translated/reviewed. `source` means gameplay acquisition, not provider.
Legacy sourceHeroCn remains compatible; reviewed IDs add links without guessing.

**ONE supplemental** `lookup-catalog.json`, no duplicate hero/tactic profiles:

```text
{schemaVersion:1,equipment:Equipment[],specials:Special[],advisors:Advisor[],
 troopMods:TroopMod[],buildings:Building[]}
Common = {id:string,nameVi:string,aliasesVi:string[],aliasesZh:string[],
          conditions:CommonLookup.conditions,missingFields:string[]}
Equipment = Common + {qualityVi:string|null,slotVi:string|null}
Special = Common + {tierVi:string|null,slotVi:string|null,descriptionVi:string|null,
                    acquisitionVi:string[],equipmentId:string|null,exclusiveHeroId:string|null}
Advisor = Common + {elementVi:string|null,effectVi:string|null,usageVi:string|null,
                    tacticPoints:number|null,heroIds:string[]}
TroopMod = Common + {effectVi:string|null,appliesToVi:string|null,suggestedBuildVi:string|null,
 troopLimitVi:string[],revisions:CommonLookup.revisions,
 options:[{id:string,tierVi:string,nameVi:string,descriptionVi:string|null,convertsToVi:string|null}]}
Building = Common + {summaryVi:string|null,mainCityOnly:boolean,maxLevel:number,
 levels:[{id:string,level:integer,costs:{wood:number|null,iron:number|null,stone:number|null},
          durationVi:string|null,effectVi:string|null}]}
```

All shapes strict whitelist; nullable only when genuinely absent. All source fields
must appear in field ledger as projected, mapped, private provenance, historical
revision or absent—no silent field loss. Extra object-valued civil/red rules get
reviewed faithful Vietnamese structured prose, not `[object Object]` serialization.
Chinese aliases allowed for search, raw descriptions only retained in legacy
effect contract; UI renders reviewed VI. No raw attributes spread into public DTO.

`lookup-manifest.json` exact `{schemaVersion:1,generationId:"lookup:"+sha256,
files:{"heroes-dict.json":sha256,"tactics.json":sha256,"lookup-catalog.json":sha256}}`.
generationId hashes canonical sorted `files` object; no input/source hashes or
timestamps public, no per-record generation field. Manifest does not hash itself.

### Field precedence and mapping

| Source → existing output | Rule |
|---|---|
| baseForce/Wisdom/Command/Speed/Politics/Charm → stats.luc/tri/thong/toc/chinh/mi | Validate finite number, stringify preserving zero. |
| adaptCavalry/Shield/Bow/Spear/Siege → troopApt.ky/thuan/cung/thuong/khiGioi | Meaningful source grade wins; other two aptitudes stay lookup fields. |
| faction / role / stars / cost | Explicit faction/VI role mapping; existing type preserved. |
| kind / quality / effectText / effectTarget | type / quality / effect / target, paired reviewed effectViet/targetViet. |
| troopLimit / source / sources | troopFit / translated acquisition / lookup.acquiredFromVi; empty troopLimit means unrestricted. |
| innateTacticId/advisorSkillId/advisor generals[].id | Validate source ref then map canonical IDs. Name-only inherit/exclusive relations require review. |

`conflictsWith` hiện chứa tên trạng thái/cơ chế (抵禦, 混亂, 反擊 / 分擔),
dịch `conflictsVi`, không biến thành tactic references. `activationRate` giữ numeric
ratio gốc (snapshot có 1, 0.25...), formatter percentage chỉ sau kiểm source UI/
field contract xác nhận scale; test real records 1 và 0.25 cùng expected label
đã review, không đoán 1% hoặc nhân đôi 100. Nếu snapshot thiếu chứng cứ scale,
đọc source UI bằng read-only, không recrawl corpus. Cooldown/pointCost 0 hợp lệ.

Missing = null/blank/observed whole-field sentinel such as 待補充. Placeholder
substrings inside real prose never erase a whole description. Valid 0/false wins;
empty troopLimit is meaningful; empty sources/conflicts means no listed relation,
not fabricate one. Invalid nonempty type/domain fails candidate, not silent fallback.
Source missing → real baseline → null/missing state. Existing vetted `iconUrl`
là asset contract, không phải provider provenance/source URL; whitelist riêng.
Review each remaining field
in schema explicitly; do not use blanket `sourceValue or legacyValue`.

### Translation and private evidence

`pipeline/lookup-translations.json`: `{schemaVersion:1,glossaryVersion:string,
entries:[{entityId,fieldPath,inputFingerprint,textVi,status:"reviewed",
review:{reviewer,reviewedAt,evidence:string[],semanticChecks:string[]}}]}`.
Fingerprint canonical selected text + target/variant/restrictions/revision/parent
context + glossary version. Fingerprint cũng bind ID/tên Việt của entities được nhắc đến qua registry; đổi
nhãn đã dịch phải invalidate các prose phụ thuộc, dù Chinese text chưa đổi.
Metadata-only refetch không invalidate. Stale effectViet must **block promotion** until
agent translates/reviews; old VI must not mask source-winning Chinese effect.
Review numbers/ranges/units/targets/trigger/duration/caps/negation manually;
automated token checks flag omissions, never substitute for semantic reading.
Separate dated/current/original revisions, never combine simultaneous mechanics.
Actual absence allows updating; translation backlog is not missing source content.

Private `<output-dir>/generation.json` (mặc định
`pipeline/lookup-output/<generationId>`, hoặc explicit `--output` bên dưới) records schema,
hashes của chính captured input buffers, builder hashes, exact output hashes,
counts/dispositions and ledger path. Input capture is immutable for the build;
source path replacement sau capture không đổi candidate đang build, còn thay đổi
trước lần build kế tiếp tạo input hash/generation mới.
`ledger.json` rows: `{entityId,fieldPath,chosenInput,sourceRecordId,sourceFieldPath,
sourceValueHash,localValueHash,reason,translationInputFingerprint,reviewEvidence}`.
Keep unresolved identities internal with reason; do not invent duplicate public
profiles. Confirmed parents/children remain published even with null relations.

## Success Criteria, risks and rollback

- [ ] Full reviewed candidate, all IDs/deltas/child relationships verified.
- [ ] Same inputs repeat same bytes, no source mutation/network/self-feeding.
- [ ] Source missing distinguished from untranslated; stale translations block.
- [ ] Public projection source-free; existing raw effect retained only for compatibility.
- [ ] Generation evidence hashes exactly the captured bytes used to build every output.

Invalid source/fingerprint fails before candidate replacement; keep last valid
candidate and input evidence. No root output touched, so rollback requires only
selecting previous private candidate. Future source refresh is a separate accepted
input promotion/review; never overwrite frozen fallback with generated output.
