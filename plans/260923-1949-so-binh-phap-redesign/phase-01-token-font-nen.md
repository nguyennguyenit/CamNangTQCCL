# Phase 1: Token, font, component nền, công cụ so ảnh

## Goal
Toàn site dùng một nguồn token máy đọc được (`tokens.json`, trích từ artboard) cho màu **và** mọi giá trị vi mô (chữ, khoảng cách, bo góc, chiều cao control, bóng…), font self-host, danh mục component dùng lại có đặc tả theo token; có công cụ so ảnh (vĩ mô, người duyệt) và đo computed style (vi mô, tự động) để soát mọi phase sau.

## Tasks & Steps
1. **Trích token từ artboard** (`scripts/design-tokens.mjs --extract`, tái dùng phần đọc artboard của `scripts/design-capture.mjs`): đọc inline style của 24 artboard trang (bỏ DirA/B/C) + `StyleGuide.dc.html` `renderVals()` (chỉ định nghĩa **màu**: sáng, tối, 5 phe), gom tần suất từng thuộc tính. Đo 2026-09-25: font-size 39 giá trị (12.5px ×331, 12px ×286, 13.5px ×282, 13px ×234, 15px ×226, 14.5px ×176…), gap 35, padding 109 tổ hợp, border-radius 15 (10 ×244, 999 ×181, 12 ×149, 14 ×64, 5 ×58, 2 ×49, 6 ×45…), line-height 17, min-height/height control 12 (44 ×86, 36 ×84, 40 ×43, 32 ×32, 52 ×26…), letter-spacing 6 (0.14em ×100…), box-shadow 5. Báo cáo tần suất đầy đủ vào `reports/visual-phase-01.md`.
1b. **`tokens.json`** (golden master vi mô): nhóm `color` (light/dark/faction, giữ tên biến đang dùng: Giấy → `--bg`, Thẻ → `--panel`, Giấy đậm → `--panel-2`, Mực → `--ink`, Chữ phụ → `--muted`, Viền → `--line`, Son → `--accent`, Son nhạt → `--accent-soft`, phe → `--f-nguy/--f-thuc/--f-ngo/--f-quan/--f-honhop`; thêm `--band` `#1C1A17`/`#0F0E0B`, `--band-ink`, `--band-muted`, `--ink-2` `#3A352D`, `--line-2` `#E6DECF`, `--accent-ink` `#8E1B24`, gạch chân nav `#E36A6F`), `font` (`--font-sans`, `--font-serif`, `--font-cjk` `'Songti TC','Noto Serif CJK TC',serif`), `type` (**vai trò chữ** gói size + line-height + weight + letter-spacing, vd `label-caps` = 11px/600/0.14em, `hero-name` = 14.5px/600, `tactic` = 13.5px/500 màu `--accent-ink`, `meta` = 12.5px…; tiêu đề trang, tên đội, số điểm là vai trò riêng với giá trị cụ thể, không dùng khoảng), `space` (thang gap/padding), `radius`, `control` (chiều cao theo vai trò; mobile tối thiểu 44 theo §11.4), `shadow`, `border`, `z`, `motion`. **Giữ đúng giá trị artboard, không làm tròn**; giá trị dùng ≤ 2 lần → gộp vào token gần nhất khi chênh ≤ 0,5px (ghi lý do) hoặc ghi là ngoại lệ có nguồn; chỗ contract thắng artboard (§11.4: 44px thay 40px…) ghi rõ. Mỗi token có `source` (artboard:dòng hoặc `renderVals`). Khối `:root` / `:root[data-theme="dark"]` trong `css/styles.css` viết theo `tokens.json`; `design-tokens.mjs --check` bảo đảm khớp. Dark: chỉ màu đổi; token vi mô dùng chung hai theme.
2. Thay mọi mã hex ngoài khối token (43 lần trên 38 dòng, vd `css/styles.css:134,164-170,218-225,241-243,257,323,361,861`) bằng token màu. **Giá trị vi mô thô** (px/em cho chữ, khoảng cách, bo góc, chiều cao, bóng…): CSS mới viết (khối token, component nền) phải sạch ngay. Toàn bộ CSS cũ **giữ nguyên vị trí và thứ tự nội bộ** (ngay sau khối token), bọc giữa hai comment `/* legacy:start ceiling=<N> */` … `/* legacy:end */`, không token hóa lúc này (Phase 3–9 viết lại, tránh làm hai lần); CSS mới đặt **sau** khối legacy để thắng cascade khi trùng selector. `design-tokens.mjs --check` báo lỗi khi có giá trị thô **ngoài** khối legacy, hoặc số giá trị thô **trong** khối vượt `ceiling`; in số theo selector vào `visual-phase-01.md` làm mốc. Mỗi phase xóa CSS cũ của mục mình viết lại khỏi khối và hạ `ceiling` xuống đúng số còn lại (không phase nào được tăng); Phase 10 xóa hẳn khối, `ceiling` = 0.
3. **Font.** Lấy file woff2 từ Google Fonts CSS2 API (User-Agent trình duyệt hiện đại), giữ đúng `unicode-range` của 3 subset; viết `@font-face` với `font-display: swap`. `--font-sans: 'Be Vietnam Pro', system-ui, sans-serif`; `--font-serif: 'Noto Serif Display', Georgia, serif`. Mục tiêu 150–250 KB (red-team đo thử 2026-09-25: 15 file, 176.504 byte). `OFL.txt` chứa bản quyền + giấy phép của cả hai font. **Nguồn gốc:** ghi vào README design URL request CSS2, URL + SHA-256 từng woff2, ngày tải.
4. **Ấn 兵:** trích outline glyph 兵 từ Noto Serif TC Bold bằng fontTools (một lần, không commit font CJK), lưu path vào component dùng ở Phase 3. fontTools chưa cài (`python3 -c 'import fontTools'` lỗi) → cài phiên bản cố định trong venv tạm ngoài repo (`pip install fonttools==<bản cụ thể>`); ghi vào README design: lệnh trích, phiên bản fontTools, URL + SHA-256 file font nguồn.
5. **Danh mục component** (mục `components` trong `tokens.json`; plan.md quyết định #16): mỗi component có `name`, `selector` (class hiện có nếu có), cấu tạo (các phần con), biến thể, trạng thái (hover/focus-visible/pressed/disabled/active), bảng thuộc tính → token (vd `padding: space.3 space.4`, `font: type.hero-name`, `min-height: control.44`), artboard nguồn, phase sở hữu, phase dùng. Tối thiểu: badge phe (ô 8px `aria-hidden` + chữ), badge loại binh, chip lọc (`aria-pressed`), nút chính/phụ/chữ, nút chiến pháp (tìm), nút khắc chế, số điểm serif son, thẻ, **dòng tướng** (vai trò · tên · chiến pháp · binh thư — dùng ở thẻ đội, Bảng, chi tiết, Khai hoang, Cùng Tồn, Soi đội), **thẻ đội**, thanh điểm, ô tìm, select có nhãn caps, bảng, menu thả, hộp thoại, focus-visible. Phase 1 làm CSS component nền (badge, chip, nút, số điểm, thẻ, ô tìm, select, focus); component phức tạp (thẻ đội, dòng tướng, bảng, menu thả, hộp thoại, thanh điểm) được **đặc tả** ở Phase 1, làm ở phase sở hữu và các phase sau dùng lại. Phase sở hữu mặc định: menu thả → Phase 3; dòng tướng, thẻ đội, bảng → Phase 5 (dùng lại ở Phase 6 thẻ tướng + khối build Khai hoang, Phase 7 "Trong cẩm nang", Phase 8 Cùng Tồn/Khai hoang, Phase 9 kết quả Soi đội/Gợi ý đội); hộp thoại → Phase 7; thanh điểm → Phase 8. Đặt tên class theo quy ước hiện có; **không đổi** các class test/code đang bắt: `.nav-tab .section .active .open .reference-team-card .reference-holder .reference-detail-holder .reference-score .team-name .scope-note .fchip .fgroup .empty .counters .ana-link-btn .reference-alternatives .detail-score .main-holder .kh-card .kh-build .kh-season-context .kh-guide .kh-guide-details .kh-opening-note .kh-build-note .kh-commander .hero .kh-note .lookup-chip .lookup-card .lookup-backdrop .clear-btn .badge.tier .coexist-subteam .team-card .stats .error .roster-results .roster-review-panel .top-header .tagline` (nguồn: `tests-e2e/*`, `tests-js/frontend-shell-contract-assertions.mjs:37-38`; `.top-header` đo ở `js/app.js:224`, `season-lookup.spec.mjs:368`; `.tagline` ở `season-lookup.spec.mjs:49`).
